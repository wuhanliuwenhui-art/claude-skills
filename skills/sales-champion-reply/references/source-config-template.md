# 资料源配置模板

安装后，应在本目录创建或检查：

```text
references/local-sources.md
```

`local-sources.md` 用来记录团队自己的飞书资料入口。不要把包含内部链接的 `local-sources.md` 提交到公开仓库。

### 销售聊天记录

- 名称：
- 链接：
- 用途：存放手动导出的企微聊天记录。
- MVP 必要字段：微信号、消息内容、所属对话、发送时间、是否托管账号发送。

建议目录结构：

```text
02.销售聊天记录/
  01.全量月度聊天记录/
  02.转化用户当月聊天记录/
```

- `01.全量月度聊天记录`：按月份存放所有用户聊天记录，是最完整事实源，用于跨月追溯完整成交路径。
- `02.转化用户当月聊天记录`：按成交月份存放当月转化用户的单人 Excel。目录内微信号默认视为已转化，可用于更新成交微信号总表；它也是快速复盘入口，但不默认代表完整成交链路。

文件命名允许保留企微原始导出名，只要求文件名或所在目录能识别月份。例如：

```text
苏赛拉新组-易之道2026-06-01-2026-06-30-1782919807140聊天历史-1.xlsx
```

如果同一个月有多个导出分片，直接保留 `-1`、`-2`、`-3`，不要求人工合并。

### 成交客户

- 名称：
- 链接：
- 用途：成交状态唯一判断依据，也是复盘成交用户的索引表。

推荐字段：微信号、成交月份、成交时间、成交产品、成交金额、备注。可选字段：首次咨询月份。

成交微信号总表可由转化用户当月聊天记录提取更新。成交月份默认取文件所在月份目录；成交时间、成交产品、成交金额只有在聊天内容中明确出现时才填写，否则标记为待确认或留空；备注中记录来源文件。

## 配置原则

- 公开 GitHub 仓库只放模板，不放内部飞书链接。
- 团队成员安装后，在本地 `references/local-sources.md` 中配置实际链接。
- 如果用户在对话里提供了飞书链接，优先使用用户提供的最新链接。
- 如果找不到本地配置，要求用户提供资料源链接，不要猜测。
