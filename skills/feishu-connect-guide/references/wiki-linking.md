# 飞书知识库挂载流程

当用户希望把某个飞书知识库作为资料库时，按这个顺序做。

## 输入

优先向用户索要以下任一内容：

1. Wiki 空间链接
2. 任意知识库页面链接

## 操作顺序

1. 先用当前身份读取页面或节点
2. 再尝试读取整个 Wiki 空间的顶层节点
3. 如果应用身份读取空间失败，但单页可读：
   - 直接切换到用户授权
4. 用户授权成功后，再次读取 Wiki 空间
5. 拉出顶层目录，确认知识库已可访问

## 对用户的话术

### 只缺链接时

```markdown
第 N 步（使用者操作）
把你要挂载的飞书知识库链接发我。可以是整个知识库空间链接，也可以是里面任意一篇页面链接。
```

### 需要用户授权时

```markdown
第 N 步（使用者操作）
应用身份只能读单页，不能展开整个知识库。下一步我会打开飞书授权页，你在浏览器里点一次“同意授权”。
做完后回复我：已授权
```

### 挂载成功时

```markdown
第 N 步（AI 操作）
- 我已经能访问这个知识库空间
- 我会先读取它的顶层目录
- 接下来可以把它设为默认资料库
```
