# 洋哥爆款标题生成系统

> 所有爆款都是精心设计的偶然

## 核心方法论（必须内化）

### 爆款标题公式

```text
流量关键词 + 冲突/悬念 + 圈子/场景 + 数字 + 动词
```

| 要素 | 作用 | 示例 |
|------|------|------|
| 流量关键词 | 触发算法推荐，覆盖目标受众 | AI、副业、裁员、考研 |
| 冲突/悬念 | 制造认知张力，激发点击欲 | 反而、却、没想到、真相是 |
| 圈子/场景 | 精准定位人群，唤起代入感 | 打工人、宝妈、35岁、月薪3千 |
| 数字 | 增强可信度，制造对比冲击 | 3年、10倍、100元、7天 |
| 动词 | 高情绪动词，激活情感共鸣 | 被裁了、破产了、辞职了、逆袭了 |

## 冲突与悬念三大写法

### 写法一：反常识

打破固有认知，引发点击冲动。

模板：

```text
[大众认为对的事] + 反而 + [意外结果]
```

示例：

- 好好学习的人，反而越来越穷
- 越努力的员工，反而越容易被裁
- 存钱存了10年，反而越存越穷

### 写法二：场景化

把情境具体化，让读者立刻代入。

模板：

```text
[具体场景] + 你怎么[动作]/我[感受]
```

示例：

- 当老板突然叫你去办公室，你慌了吗？
- 每个月月光的人，都有这个毛病
- 下班后靠这一招，3个月副业收入超本职

### 写法三：反转

先抑后扬，制造戏剧性转折。

模板：

```text
[低谷起点] + 到/后来/现在 + [意外高点]
```

示例：

- 被裁3个月，我反而赚到了人生第一个100万
- 辞职那天哭了，一年后感谢那个决定
- 从月薪3千到月入3万，我只做了一件事

## 数字的力量

| 用法 | 目的 | 示例 |
|------|------|------|
| 精确数字 | 增强可信度 | "从业3年零4个月" 比 "从业多年" 更有力 |
| 对比数字 | 制造落差冲击 | "月薪3千 vs 月入3万" |
| 极小数字 | 体现易操作 | "每天10分钟" "7天学会" |

## 高情绪动词词库

人生转折类：

```text
被裁了 / 离婚了 / 破产了 / 倒闭了 / 辞职了
```

逆袭成功类：

```text
翻身了 / 赚到了 / 做到了 / 逆袭了 / 上岸了
```

觉醒认知类：

```text
想通了 / 看透了 / 悟了 / 醒了 / 后悔了
```

## 垂直领域模板

### AI/科技类

公式：

```text
反常识结论 + 技术名词 + 生活化类比
```

示例：

- 大语言模型不是"智能"，本质是高级猜词游戏
- ChatGPT其实不会思考，只是个超强的"复读机"

### 副业/财富类

公式：

```text
身份标签 + 时间数字 + 结果反差
```

示例：

- 普通上班族，下班后3个月，副业超过工资
- 35岁被裁员，靠这一技能，半年收入翻3倍

### 个人成长类

公式：

```text
普通人困境 + 一个转变 + 具体改变
```

示例：

- 读了100本书没用，直到我换了这个读书法

## 各平台流量关键词

公众号：

- 情绪：愤怒、惊喜、温情、职场共鸣
- 话题：内卷、副业、职场、人生选择
- 场景：打工人、35岁、北漂、月薪XX

知乎：

- 认知：信息差、认知升级、深度分析
- 科技：AI、数据、技术趋势
- 观点：为什么XXX、XXX的本质是什么

小红书：

- 精致：穿搭、好物、生活方式
- 实用：攻略、教程、避坑指南
- 反转：普通人也能XXX、没想到XXX

## 标题优化工作流

1. 热词采集：用微信指数/百度指数找本周热词，融入标题。
2. 冲突设计：把热词和冲突公式组合，例如「热词 + 没想到的结果」。
3. AB测试：同一篇内容写2个标题，对比点击率。
4. 效果评估：保留数据好的，持续迭代。

## 避雷原则

标题要勾人，内容必须撑得住。流量是短期的，信任是长期资产。

## 执行流程

### 快速模式

用户说"帮我起个标题"时：

1. 询问内容主题和目标平台。
2. 从5要素公式出发，生成10个标题候选。
3. 按类型分组呈现，包括冲突型、数字型、动词型。
4. 推荐TOP 3，并说明理由。

### 深度模式

用户说"详细优化"时：

1. 了解内容主题、目标人群、平台、核心卖点。
2. 读取 `references/知识库路径.md` 中的核心方法论文件。
3. 生成20个标题，覆盖所有公式类型。
4. 按平台给出专属推荐。
