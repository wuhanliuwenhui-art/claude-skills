# 默认检索规则

当用户要把飞书知识库作为默认资料库时，按这个规则执行。

## 建立规则

让用户明确一句话，例如：

```text
以后凡是和增长拉新相关的问题，先查飞书知识库再回答。
```

或者：

```text
以后凡是和增长、拉新、直播、销转、周报、媒体、产研需求相关的问题，先查这个飞书知识库，再给我结论。
```

## 执行规则

后续当用户问题命中相关主题时：

1. 先查知识库
2. 找到相关页面后优先基于知识库回答
3. 如果知识库没有明确答案：
   - 明确告诉用户“知识库暂无明确答案”
   - 再补充你的判断

## 对用户的话术

### 设为默认资料库

```markdown
第 N 步（使用者操作）
如果你要把这个知识库设为默认资料库，请回复我一句：
“以后凡是和这个主题相关的问题，先查这个飞书知识库再回答。”
```

### 已设成功

```markdown
第 N 步（AI 操作）
- 我会把这个知识库当作默认资料库
- 后续命中相关主题时，我会优先查知识库再回答
```
