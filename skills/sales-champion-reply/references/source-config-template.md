# 资料源配置模板

安装后，应在本目录创建或检查：

```text
references/local-sources.md
```

`local-sources.md` 用来记录团队自己的飞书资料入口。不要把包含内部链接的 `local-sources.md` 提交到公开仓库。

## 配置原则

- 公开 GitHub 仓库只放模板，不放内部飞书链接。
- 团队成员安装后，在本地 `references/local-sources.md` 中配置实际链接。
- 如果用户在对话里提供了飞书链接，优先使用用户提供的最新链接。
- 如果找不到本地配置，要求用户提供资料源链接，不要猜测。
